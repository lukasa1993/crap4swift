# crap4swift

Use this command as the Swift quality gate in SwarmForge.

## Install

```bash
python -m pip install --upgrade "git+https://github.com/lukasa1993/crap4swift.git"
```

## Verify

Read `README.md`, inspect `crap4swift --help`, and run the command from the project root. Keep generated reports under `target/` and do not commit them.
